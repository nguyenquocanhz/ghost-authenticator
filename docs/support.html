Frequently Asked Questions (FAQ)

Why is my 2FA code showing "Invalid Code" when logging in? +

TOTP (Time-based One-Time Passwords) rely heavily on exact time synchronization. If your Windows PC clock is even 30 to 60 seconds off from standard UTC time, the generated OTP code will not match the server's expected code.

Solution: Open Windows Settings → Time & Language → Date & Time, and click "Sync now" to synchronize your clock with Windows time servers (time.windows.com).

How are my 2FA secret keys encrypted? +

Ghost Authenticator utilizes authenticated AES-256 GCM encryption. The key is derived using PBKDF2 with SHA-256 (100,000 rounds) combined with a cryptographically random salt. This makes brute-force attacks computationally infeasible.

Can the developer recover my forgotten master password? +

No. Ghost Authenticator is designed on a zero-knowledge architecture. There are no backdoor keys or remote recovery servers. If you forget your master password, your encrypted local database cannot be recovered. Always store a backup of your emergency 2FA backup codes in a safe place.

Does Ghost Authenticator send my data to cloud servers? +

No. The application is 100% offline-first. It does not communicate with external servers, telemetry collectors, or cloud analytics. All authentication calculations occur strictly in-memory on your local CPU.

Which Windows versions are supported? +

Ghost Authenticator requires Windows 10 (version 19041 / 2004 or newer) and Windows 11 (64-bit x64 or ARM64 architecture).

How do I cleanly uninstall Ghost Authenticator? +

If installed via Microsoft Store, simply right-click Ghost Authenticator in the Start Menu and select Uninstall. Windows Store takes care of removing all application binaries and its sandboxed storage cleanly (in accordance with Store Policy 10.2.7).
